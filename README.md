# aya-lang-hehe 💗

An interactive and charming date request website built with vanilla HTML, CSS, and JavaScript. This project creates a cute, playful multi-page experience to ask someone out on a date!

## Features ✨

- **Interactive Multi-Page Flow** - Guides through 4 screens of the date planning process
- **Evasive NO Button** - The "NO" button runs away when you try to click it (playful prank!)
- **Date & Time Selection** - Pick a specific date and choose from 12 different time slots
- **Restaurant/Food Chooser** - Select from 6 different dining options:
  - 🍗 Jollibee
  - 🛍️ Bazaar
  - 🍽️ Kusina sa Danao
  - 🌭 Street Food
  - 🐙 Takoyaki
  - 🍢 Quik² Tempura & Fish Ball
- **Animated Hearts** - Floating heart animations throughout the experience
- **Form Validation** - Ensures all required fields are selected before proceeding
- **Beautiful Design** - Gradient pink/rose color scheme with smooth animations
- **Fully Responsive** - Works perfectly on mobile and desktop devices

## How It Works 🚀

1. **Screen 1** - Ask the big question with a cheeky NO button that won't stay still
2. **Screen 2** - Select a date and preferred time for the date
3. **Screen 3** - Choose where to eat together
4. **Screen 4** - See the date confirmation with all details

## Usage 

Simply open `index.html` in your web browser. The entire experience is contained in a single HTML file with embedded CSS and JavaScript.

```bash
# Just open the file directly
open index.html
# or
# Double-click index.html in your file explorer
```

## Customization 🎨

You can easily customize:
- **Colors** - Change the pink theme in the CSS (look for `#c83e72` for the primary color)
- **Restaurants** - Add more food options in Screen 3
- **Time Slots** - Modify the available time options
- **Messages** - Update the text to match your personality
- **Emojis** - Use different emojis throughout for different vibes
